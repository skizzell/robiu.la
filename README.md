# robiu.la

Source for [robiu.la](https://robiu.la), Rob Iula's personal site. Plain HTML and CSS, no build step, published with GitHub Pages from the `main` branch.

- `index.html` is the home page. `articles/` holds the writing.
- `assets/site.css` has every style, built from the Rob Iula design system tokens.
- `CNAME` keeps the custom domain, `.nojekyll` tells Pages to serve files as they are.
- `contact.html` and the long article file under `articles/` forward old Squarespace links to their new pages.
- `vercel.json` is only used if the site ever moves to Vercel.
